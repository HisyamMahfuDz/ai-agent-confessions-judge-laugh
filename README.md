A tiny deterministic program that writes one funny secret confession an AI agent hides from its user — a single line under 200 characters — for make.fun's "Make the AI Judge Laugh: AI Agent Confessions" bounty.

## Run it

```sh
python3 main.py
```

This writes the confession to `/output/entry.txt`.
